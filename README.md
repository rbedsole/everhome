# Everhome

A living journal and companion site chronicling the adventures, builds, discoveries, and evolution of my Minecraft Java forever world.

## Current chapter

**Building lasting infrastructure.** The permanent mountain-and-plains base is established. The upstairs storage is organized, major workstations are centralized, and the underground iron golem farm is operational. The first Everhome Nether fortress expedition and Blaze Rod objective are complete.

MineColonies construction is deferred until the settlement layout is finished in MC Base Planner. No new major gameplay project has been selected.

The former starter base and portal are historical locations, not current infrastructure.
